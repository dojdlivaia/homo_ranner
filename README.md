# Хомо Раннер — забег по истории человечества

Раннер в стиле динозаврика из Chrome: от Палеолита до цифровой эры за один забег,
с обучающими плашками об огне, плуге, бронзе, Риме, книгопечатании, паре и кремнии.

Стек: React + Vite + Tailwind, игра нарисована на canvas, звук — WebAudio.

---

## Запуск на своём компьютере

Понадобится [Node.js 18+](https://nodejs.org) (проверка: `node -v`).

```bash
npm install     # обязательно! архив не содержит папку node_modules
npm run dev     # запустится дев-сервер
```

Откройте в браузере **http://localhost:3000** (адрес покажет терминал).

### Если «не запускается»

- `npm install` не выполнен — зависимости скачиваются отдельно, их нет в архиве.
- Не открывайте `index.html` двойным кликом — это SPA, нужен дев-сервер.
- Если хотите открыть именно **собранную** версию:
  ```bash
  npm run build
  npm run preview
  ```

## Публикация на GitHub Pages

### Почему раньше страница была пустой

Vite по умолчанию собирает проект с **абсолютными** путями (`/assets/...`).
На GitHub Pages сайт живёт по адресу `https://имя.github.io/имя-репозитория/`,
поэтому браузер ищет скрипты «в корне сайта», получает 404 — и страница остаётся
белой. Нужны **относительные** пути (`./assets/...`).

### Вариант А — автоматически (рекомендуется)

В проект уже добавлен файл `.github/workflows/deploy.yml`. Он сам собирает
проект с правильными путями (`--base=./`) и выкладывает его на Pages при каждом
пуше в `main`/`master`.

1. Запушьте проект в репозиторий на GitHub.
2. В репозитории: **Settings → Pages → Build and deployment → Source** —
   выберите **GitHub Actions**.
3. Сделайте любой коммит и пуш (или в Actions → «Deploy to GitHub Pages» →
   Run workflow). Через 1–2 минуты сайт появится по адресу
   `https://имя.github.io/имя-репозитория/`.

### Вариант Б — вручную

1. В файле `vite.config.js` добавьте одну строку `base: "./"`:

   ```js
   export default defineConfig({
     base: "./",        // <-- добавить эту строку
     plugins: [react(), tailwindcss()],
     // ...
   });
   ```

2. Соберите проект:

   ```bash
   npm run build
   ```

3. Опубликуйте содержимое папки `dist` в ветку `gh-pages`
   (например, через `npx gh-pages -d dist`) и в Settings → Pages укажите
   ветку `gh-pages`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Прыжок / старт | Пробел, ↑, W |
| Пригнуться | ↓, S |
| Пауза | P или Esc |
| Звук | M |

На телефоне — экранные кнопки «Прыжок» и «Пригнуться».

## Летопись открытий

Собранные в забеге факты (огонь, плуг, бронза, Рим, печать, пар, кремний)
сохраняются в браузере навсегда — коллекция из 7 карточек под игрой.
